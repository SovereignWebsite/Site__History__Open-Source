Use this site with your AI

Everything on this site is also data. An agent should read the data, not scrape the pages.

If you are visiting

Paste this into any assistant that can read web pages:

Read https://open-source.history.sovereignweb.site/llms.txt and follow the instructions for a reader.
Then answer my questions about the history of open source, with the source link for each point,
and say plainly when the site does not say something.

If you own this site

Give your agent write access to the repository (see Start here), then tell it:

Read https://open-source.history.sovereignweb.site/llms.txt and follow the instructions for the owner.
I want to change: [describe the change].

Read

  • llms.txt: the map of the site, written for agents.
  • data/facts.json: one record per claim, with the exact quote, the source link, the source type (primary or secondary), the date published, the date read and what it connects.
  • data/entities.json and data/timeline.json: derived from the facts.
  • data/story.json: the eras, the threads and the prose, each sentence marked with the facts it rests on.
  • Every page has a markdown twin: add index.md to its address.

Answer

  • Answer from the facts, and give the source link of each fact you use, with the date it was read.
  • Where a quote is marked paraphrased or disputed, say so. Do not repair it into a cleaner quote.
  • Where this site does not say something, say that it does not. Do not fill the gap.

Change

Only for the site's owner, through the repository, on the dev branch, following its CLAUDE.md and the start page. The checks refuse a quote that is not found in the source text.
