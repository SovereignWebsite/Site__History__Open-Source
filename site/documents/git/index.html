The facts

2005 Hostility and adoption

Git was created in 2005 by Linus Torvalds and the Linux kernel community after they lost free use of the proprietary BitKeeper tool.

In 2005, the relationship between the community that developed the Linux kernel and the commercial company that developed BitKeeper broke down, and the tool’s free-of-charge status was revoked. This prompted the Linux development community (and in particular Linus Torvalds, the creator of Linux) to develop their own tool

Secondary source: book Pro Git, 1.2 Getting Started: A Short History of Git, git-scm.com (Apress), by Scott Chacon and Ben Straub. Read 27 November 2026.

From the Pro Git book hosted on the Git project's site. Torvalds's own 2005 messages on lore.kernel.org were behind a bot challenge and could not be read.

Connects: Linus Torvalds, Git

2005 Hostility and adoption

The README in the first revision of Git describes it as a stupid but extremely fast directory content manager.

This is a stupid (but extremely fast) directory content manager. It doesn't do a whole lot, but what it _does_ do is track directory contents efficiently.

Primary source: document README in the initial revision of git (commit e83c5163), git project (GitHub mirror), by Linus Torvalds, published 2005. Read 27 November 2026.

The README is read from the first commit in the Git repository (e83c5163); the file itself carries no date, so only the year is given.

Connects: Linus Torvalds, Git

23 February 2008 Hostility and adoption

GitHub added pull requests in February 2008, while the site was still in beta.

Last night I pushed out a feature Tom and I have been talking about since day one: pull requests.

Primary source: own-post Oh yeah, there's pull requests now, The GitHub Blog, by Chris Wanstrath, published 23 February 2008. Read 27 November 2026.

Connects: GitHub, Git
