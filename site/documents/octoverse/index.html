29 October 2024 Strain and stewardship

GitHub reported for 2024 more than 5.2 billion contributions to more than 518 million projects, a figure that mixes open source, public and private work.

In 2024, developers around the world made more than 5.2 billion contributions to more than 518 million open source, public, and private projects.

Primary source: report Octoverse: AI leads Python to top language as the number of global developers surges, The GitHub Blog, by GitHub Staff, published 29 October 2024. Read 27 November 2026.

GitHub's own figures; they cover private projects as well and are not a measure of open source alone.

28 October 2025 Strain and stewardship

GitHub reported in October 2025 that more than 180 million developers use the platform, 36 million of whom joined in the past year.

Every second, more than one new developer on average joined GitHub—over 36 million in the past year. It’s our fastest absolute growth rate yet and 180 million-plus developers now work and build on GitHub.

Primary source: report Octoverse: A new developer joins GitHub every second as AI leads TypeScript to #1, The GitHub Blog, by GitHub Staff, published 28 October 2025. Read 27 November 2026.

GitHub's own figures for accounts on its platform.
