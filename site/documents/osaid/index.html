The Open Source AI Definition 1.0

The OSI's definition of open source for AI systems12.

The facts

22 October 2024 Strain and stewardship

A week earlier the Free Software Foundation had said its own criteria for free machine learning applications would require the raw training data to carry the four freedoms.

it is working on a statement of criteria for free machine learning applications, which will require the software, as well as the raw training data and associated scripts, to grant users the four freedoms.

Primary source: press-release FSF is working on freedom in machine learning applications, Free Software Foundation, published 22 October 2024. Read 27 November 2026.

28 October 2024 Strain and stewardship

On 28 October 2024 the Open Source Initiative released version 1.0 of its Open Source AI Definition.

After a year-long, global, community design process, the Open Source Definition (OSAID) v.1.0 is available for public use.

Primary source: press-release The Open Source Initiative Announces the Release of the Industry's First Open Source AI Definition, Open Source Initiative, published 28 October 2024. Read 27 November 2026.

The release sentence says "the Open Source Definition (OSAID)"; the document released is the Open Source AI Definition.

Connects: Open Source Initiative, The Open Source AI Definition 1.0

Link to this fact

28 October 2024 Strain and stewardship

The Open Source AI Definition requires detailed information about the training data, enough for a skilled person to build a substantially equivalent system, but not the training data itself.

Data Information: Sufficiently detailed information about the data used to train the system so that a skilled person can build a substantially equivalent system.

Primary source: document The Open Source AI Definition 1.0, Open Source Initiative, published 28 October 2024. Read 27 November 2026.

That the data itself is not required is the reading of the definition's text and is the point its critics attack; see the Software Freedom Conservancy and FSF facts.

Connects: Open Source Initiative, The Open Source AI Definition 1.0

Link to this fact

31 October 2024 Strain and stewardship

The Software Freedom Conservancy's Bradley Kuhn criticised the definition for not requiring public disclosure of training sets, and said the OSI should not have published it yet.

the OSAID fails to require reproducibility by the public of the scientific process of building these systems, because the OSAID fails to place sufficient requirements on the licensing and public disclosure of training sets

Primary source: own-post Open Source AI Definition Erodes the Meaning of "Open Source", Software Freedom Conservancy, by Bradley M. Kuhn, published 31 October 2024. Read 27 November 2026.

Connects: Software Freedom Conservancy, Open Source Initiative, The Open Source AI Definition 1.0
