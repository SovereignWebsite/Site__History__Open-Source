# Mainstream

2009 to 2017.

In these years even the largest opponent joined in: Microsoft contributed to the Linux kernel [1] and, under Satya Nadella, declared that it loved Linux [2] [3], opened .NET and Visual Studio Code [4] [5] and joined the Linux Foundation [6]. Google open sourced Kubernetes, which then moved to a foundation [7] [8]. Heartbleed showed the cost of depending on underfunded projects [9].

## The facts of this era

### 2009: The first devopsdays conference was held in Ghent, Belgium, in 2009.

> The first devopsdays was held in Ghent, Belgium in 2009.

- Source (primary, document): [About devopsdays](https://devopsdays.org/about/), devopsdays. Read 27 November 2026.
- Note: It is usually said that this conference gave the DevOps movement its name; that is not stated on this page and is not claimed here.
- Connects: First devopsdays
- Fact id: `devopsdays-2009`

> This is the first time Microsoft is contributing code to the Linux kernel

- Source (primary, own-post): [Linux ICs for Hyper-V and GPLv2](https://techcommunity.microsoft.com/blog/virtualization/linux-ics-for-hyper-v-and-gplv2/381647), Microsoft (Virtualization blog, first published on TechNet), published 20 July 2009. Read 27 November 2026.
- Connects: Microsoft
- Fact id: `microsoft-first-kernel-contribution-2009`

### 20 July 2009: On 20 July 2009 Microsoft released 20,000 lines of Hyper-V driver code for the Linux kernel under version 2 of the GPL.

> In what many may see as a surprising move, Microsoft today released 20,000 lines of device driver code to the Linux community under the popular General Public Licence v2.

- Source (primary, own-post): [Microsoft Releases Device Driver Code to the Linux Community](https://learn.microsoft.com/en-us/archive/blogs/port25/microsoft-releases-device-driver-code-to-the-linux-community), Microsoft (Port 25 blog, archived on Microsoft Learn), published 20 July 2009. Read 27 November 2026.
- Connects: Microsoft, GNU General Public License
- Fact id: `microsoft-linux-kernel-2009`

### 10 September 2009: In September 2009 Microsoft sponsored the new CodePlex Foundation with $1 million, to help software companies and open source communities exchange code.

> The Foundation's mission to help the exchange of code and understanding between software companies and open source communities is really interesting to Microsoft. To help the Foundation fund its first year of operations, Microsoft is donating U.S. $1 million

- Source (primary, own-post): [The CodePlex Foundation Debuts](https://learn.microsoft.com/en-us/archive/blogs/port25/the-codeplex-foundation-debuts), Microsoft (Port 25 blog, archived on Microsoft Learn), published 10 September 2009. Read 27 November 2026.
- Note: From Microsoft's Port 25 blog, quoting Bill Staples of Microsoft. The foundation was later renamed the Outercurve Foundation; no primary source for the renaming or for the 2006 launch of the CodePlex hosting site was fetched.
- Connects: Microsoft, CodePlex Foundation
- Fact id: `codeplex-foundation-2009`

### 2 August 2010: An early practitioner definition of DevOps (2010) traces it to "agile infrastructure": applying Agile and Lean approaches to operations work.

> DevOps emerged from the collision of two major related trends. The first was called “agile infrastructure” or “agile operations”; it sprang from applying Agile and Lean approaches to operations work.

- Source (secondary, reporting): [What Is DevOps?](https://theagileadmin.com/what-is-devops/), the agile admin, published 2 August 2010. Read 27 November 2026.
- Note: A practitioner's blog, used as a contemporary secondary description; it is one view of the origins.
- Fact id: `devops-from-agile-2010`

### 7 April 2014: In April 2014 the Heartbleed bug in the open source OpenSSL library exposed information protected by the encryption that secures much of the internet.

> The Heartbleed Bug is a serious vulnerability in the popular OpenSSL cryptographic software library. This weakness allows stealing the information protected, under normal conditions, by the SSL/TLS encryption used to secure the Internet.

- Source (primary, report): [The Heartbleed Bug](https://heartbleed.com/), Codenomicon (heartbleed.com), published 2014. Read 27 November 2026.
- Note: The date is that of the fixed release: the same page says "OpenSSL 1.0.1g released on 7th of April 2014 fixes the bug."
- Connects: Heartbleed
- Fact id: `heartbleed-2014`

- Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco
- Fact id: `microsoft-loves-linux-2014`
