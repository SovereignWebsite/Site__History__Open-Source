## The facts

### 27 September 1983: On 27 September 1983 Richard Stallman announced on Usenet that he would write a complete Unix-compatible system called GNU and give it away.

> Starting this Thanksgiving I am going to write a complete Unix-compatible software system called GNU (for Gnu's Not Unix)

- Source (primary, mailing-list): [Initial Announcement (new Unix implementation)](http://www.gnu.org/gnu/initial-announcement.html), GNU Project (Free Software Foundation), published 27 September 1983. Read 27 November 2026.
