## The facts

### 22 January 1998: On 22 January 1998 Netscape announced that it would publish the source code of the next generation of its Communicator browser.

> MOUNTAIN VIEW, Calif. (January 22, 1998) — Netscape Communications Corporation (NASDAQ: NSCP) today announced bold plans to make the source code for the next generation of its highly popular Netscape Communicator client software available for free licensing on the Internet.

- Source (primary, press-release): [January 22, 1998: the Beginning of Mozilla (reproduces the Netscape press release in full)](https://blog.lizardwrangler.com/?p=187), Mitchell Baker's blog (Lizard Wrangling), published 22 January 1998. Read 27 November 2026.
- Note: The press release is read as reproduced in full by Mitchell Baker (later chair of Mozilla) on her blog in 2008. The same opening paragraph was forwarded to the Linux kernel mailing list on 22 January 1998. The Netscape original survives only in the Internet Archive, which could not be reached from this machine.
- Connects: Netscape Communications, Netscape source code announcement
- Fact id: `netscape-announcement-1998`

### 22 January 1998: Netscape said its source licence would allow modification and redistribution and would build on the heritage of the GPL.

> The company will handle free source distribution with a license which allows source code modification and redistribution and provides for free availability of source code versions, building on the heritage of the GNU Public License (GPL), familiar to developers on the Net.

- Source (primary, press-release): [January 22, 1998: the Beginning of Mozilla (reproduces the Netscape press release in full)](https://blog.lizardwrangler.com/?p=187), Mitchell Baker's blog (Lizard Wrangling), published 22 January 1998. Read 27 November 2026.
- Note: Same reproduction of the press release as above. The release says "GNU Public License"; the licence's name is the GNU General Public License.
- Connects: Netscape Communications, GNU General Public License, Netscape source code announcement
- Fact id: `netscape-licence-gpl-heritage-1998`
