# Apache Group and Apache Software Foundation

The group behind the Apache web server (1995), incorporated as a foundation in 1999 [1] [2].

## The facts

### February 1995: The Apache Group formed in February 1995, when eight webmasters began co-ordinating their patches to the NCSA web server.

> By the end of February, eight core contributors formed the foundation of the original Apache Group

- Source (primary, document): [About the Apache HTTP Server Project](https://httpd.apache.org/ABOUT_APACHE.html), The Apache Software Foundation. Read 27 November 2026.
- Connects: Brian Behlendorf, Apache Group and Apache Software Foundation
- Fact id: `apache-group-1995`

### 30 June 1999: On 30 June 1999 the Apache Group announced that it had incorporated as the Apache Software Foundation.

> The Apache Group today announced the creation of the Apache Software Foundation (ASF), to formally shepherd the development of the #1 Web server worldwide

- Source (primary, press-release): [The Apache Group incorporates to become the Apache Software Foundation](https://www.apache.org/foundation/press/pr_1999_06_30.txt), The Apache Software Foundation, published 30 June 1999. Read 27 November 2026.
- Connects: Apache Group and Apache Software Foundation
- Fact id: `asf-incorporated-1999`

### December 2021: The Log4Shell vulnerability (CVE-2021-44228) in the Apache Log4j logging library allowed attackers to run arbitrary code; Apache rates it 10.0, critical.

> JNDI lookup can be exploited to execute arbitrary code loaded from an LDAP server

- Source (primary, report): [Apache Logging Services: Security (vulnerability reports)](https://logging.apache.org/security.html), The Apache Software Foundation. Read 27 November 2026.
- Note: From the Apache Logging Services security page, which lists the CVSS score as "10.0 CRITICAL" and credits Chen Zhaojun of Alibaba Cloud Security Team with the discovery. The page gives no disclosure date; December 2021 is from the CVE number and the wider record. The CISA statement returned 403.
- Connects: Apache Group and Apache Software Foundation, Log4Shell
- Fact id: `log4shell-2021`
