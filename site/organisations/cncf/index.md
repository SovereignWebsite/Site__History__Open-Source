## The facts

### 21 July 2015: The Linux Foundation announced the Cloud Native Computing Foundation on 21 July 2015.

> The Linux Foundation, the nonprofit organization dedicated to accelerating the growth of Linux and collaborative development, today announced the Cloud Native Computing Foundation.

- Source (primary, press-release): [New Cloud Native Computing Foundation to drive alignment among container technologies](https://www.cncf.io/announcements/2015/06/21/new-cloud-native-computing-foundation-to-drive-alignment-among-container-technologies/), Cloud Native Computing Foundation (The Linux Foundation), published 21 July 2015. Read 27 November 2026.
- Connects: The Linux Foundation, Cloud Native Computing Foundation
- Fact id: `cncf-founded-2015`

### 10 March 2016: On 10 March 2016 the Cloud Native Computing Foundation accepted Kubernetes as its first hosted project.

> today announced that Kubernetes has been accepted by the Technical Oversight Committee (TOC) and its IP will be transferred to the Foundation.

- Source (primary, press-release): [Cloud Native Computing Foundation accepts Kubernetes as first hosted project; Technical Oversight Committee elected](https://www.cncf.io/blog/2016/03/10/cloud-native-computing-foundation-accepts-kubernetes-as-first-hosted-project-technical-oversight-committee-elected/), Cloud Native Computing Foundation, published 10 March 2016. Read 27 November 2026.
- Connects: Cloud Native Computing Foundation, Kubernetes
- Fact id: `kubernetes-joins-cncf-2016`
