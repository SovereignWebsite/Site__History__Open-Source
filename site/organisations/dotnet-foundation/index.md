# .NET Foundation

## The facts

### 12 November 2014: On 12 November 2014 Microsoft announced it was open sourcing the server-side .NET stack and bringing .NET to Linux and Mac OS, working through the .NET Foundation.

> Microsoft Corp. reinforced its commitment to cross-platform developer experiences by open sourcing the full server-side .NET stack and expanding .NET to run on the Linux and Mac OS platforms.

- Source (primary, press-release): [Microsoft takes .NET open source and cross-platform, adds new development capabilities with Visual Studio 2015, .NET 2015 and Visual Studio Online](https://news.microsoft.com/2014/11/12/microsoft-takes-net-open-source-and-cross-platform-adds-new-development-capabilities-with-visual-studio-2015-net-2015-and-visual-studio-online/), Microsoft, published 12 November 2014.
