## The facts

### October 1985: The Free Software Foundation was founded in October 1985, at first to raise money for the development of GNU.

> The Free Software Foundation was founded in October 1985, initially to raise funds to help develop GNU.

- Source (primary, document): [Overview of the GNU System](http://www.gnu.org/gnu/gnu-history.html), GNU Project (Free Software Foundation). Read 27 November 2026.
- Connects: Free Software Foundation, GNU Project
- Fact id: `fsf-founded-1985`

### February 1989: Version 1 of the GNU General Public License, dated February 1989, states its purpose as guaranteeing the freedom to share and change free software.

> our General Public License is intended to guarantee your freedom to share and change free software--to make sure the software is free for all its users.

- Source (primary, licence): [GNU General Public License, version 1](http://www.gnu.org/licenses/old-licenses/gpl-1.0.txt), Free Software Foundation, published February 1989. Read 27 November 2026.
- Connects: Free Software Foundation, GNU General Public License
- Fact id: `gpl-v1-1989`

### June 1991: Version 2 of the GNU General Public License is dated June 1991.

> Version 2, June 1991

- Source (primary, licence): [GNU General Public License, version 2](http://www.gnu.org/licenses/old-licenses/gpl-2.0.txt), Free Software Foundation, published June 1991. Read 27 November 2026.
- Connects: Free Software Foundation, GNU General Public License
- Fact id: `gpl-v2-1991`

### 1996: The Free Software Definition says a program is free software when its users have four essential freedoms: to run it, to study and change it, to redistribute copies and to distribute modified versions.

> A program is free software if the program's users (referred to individually here as “you”) have the four essential freedoms

- Source (primary, document): [What is Free Software? (The Free Software Definition)](http://www.gnu.org/philosophy/free-sw.html), GNU Project (Free Software Foundation). Read 27 November 2026.
- Note: The definition is a living document; the quote is from the current text. Its footnote says "Around 1990 there were three freedoms, numbered 1, 2 and 3", with freedom 0 added later, so the wording has changed over time. The date is the first copyright year on the page (1996), not the date of the idea.
- Connects: Free Software Foundation, GNU Project, The Free Software Definition
- Fact id: `four-freedoms`

### 1996: The GNU Project explains that "free" in free software is a matter of liberty and not of price.

> you should think of “free” as in “free speech,” not as in “free beer.”

- Source (primary, document): [What is Free Software? (The Free Software Definition)](http://www.gnu.org/philosophy/free-sw.html), GNU Project (Free Software Foundation). Read 27 November 2026.
- Note: The date is the first copyright year on the page (1996); the phrase is quoted from the current text.
- Connects: Free Software Foundation, The Free Software Definition
- Fact id: `free-as-in-speech`

### November 2006: In November 2006 Sun Microsystems committed to releasing Java under the GPL, a move the Free Software Foundation welcomed.

> The Free Software Foundation (FSF) welcomed the public commitment from Sun Microsystems to distribute its proprietary Java platform under the GNU General Public License (GPL)

- Source (primary, press-release): [Sun begins releasing Java under the GPL](https://www.fsf.org/news/fsf-welcomes-gpl-java.html), Free Software Foundation, published 15 November 2006. Read 27 November 2026.
- Note: This is the FSF's press release of 15 November 2006, primary for the FSF's reaction and second-hand for Sun's announcement; Sun's own release (13 November 2006 by other accounts) is no longer online and could not be fetched.
- Connects: Richard Stallman, Sun Microsystems, Free Software Foundation, GNU General Public License
- Fact id: `sun-java-gpl-2006`

### 2007: Stallman's position is that free software is a movement for users' freedom while open source values mainly practical advantage, and that the GNU Project therefore does not use the term "open source".

> The free software movement campaigns for freedom for the users of computing; it is a movement for freedom and justice. By contrast, the open source idea values mainly practical advantage and does not campaign for principles. This is why we do not agree with open source, and do not use that term.

- Source (primary, own-post): [Why Open Source Misses the Point of Free Software](http://www.gnu.org/philosophy/open-source-misses-the-point.html), GNU Project (Free Software Foundation), published 2007. Read 27 November 2026.
- Note: Dated to the first copyright year of the essay (2007); the essay has been revised since and the current text was read.
- Connects: Richard Stallman, Free Software Foundation, Why Open Source Misses the Point of Free Software
- Fact id: `stallman-open-source-misses-point`

### 29 June 2007: The Free Software Foundation released version 3 of the GPL on 29 June 2007, adding protection against locked-down devices and an explicit patent licence.

> Version 3 of the GNU GPL strengthens this guarantee, by ensuring that users can modify the free software on their personal and household devices, and granting patent licenses to every user.

- Source (primary, press-release): [FSF releases the GNU General Public License, version 3](https://www.fsf.org/news/gplv3_launched), Free Software Foundation, published 29 June 2007. Read 27 November 2026.
- Connects: Richard Stallman, Free Software Foundation, GNU General Public License
- Fact id: `gplv3-released-2007`

### 22 October 2024: A week earlier the Free Software Foundation had said its own criteria for free machine learning applications would require the raw training data to carry the four freedoms.

> it is working on a statement of criteria for free machine learning applications, which will require the software, as well as the raw training data and associated scripts, to grant users the four freedoms.

- Source (primary, press-release): [FSF is working on freedom in machine learning applications](https://www.fsf.org/news/fsf-is-working-on-freedom-in-machine-learning-applications), Free Software Foundation, published 22 October 2024. Read 27 November 2026.
- Connects: Free Software Foundation, The Open Source AI Definition 1.0
- Fact id: `fsf-ml-training-data-2024`
