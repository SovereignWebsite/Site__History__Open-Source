23 February 2008 Hostility and adoption

GitHub added pull requests in February 2008, while the site was still in beta.

Last night I pushed out a feature Tom and I have been talking about since day one: pull requests.

Primary source: own-post Oh yeah, there's pull requests now, The GitHub Blog, by Chris Wanstrath, published 23 February 2008. Read 27 November 2026.

Connects: GitHub, Git

GitHub launched publicly on 10 April 2008.

GitHub is officially live. Thanks for the awesome beta everyone.

Primary source: own-post We Launched, The GitHub Blog, by Chris Wanstrath, published 10 April 2008. Read 27 November 2026.

18 November 2015 Mainstream

On 18 November 2015 Microsoft released Visual Studio Code as an open source project on GitHub.

Microsoft released Visual Studio Code beta as an open source project, available on GitHub.

Primary source: press-release Microsoft empowers developers with new and updated tools spanning Android, Azure, iOS, Linux, Office and Windows, Microsoft, published 18 November 2015. Read 27 November 2026.

On 4 June 2018 Microsoft announced it would buy GitHub for $7.5 billion in stock.

Under the terms of the agreement, Microsoft will acquire GitHub for $7.5 billion in Microsoft stock.

Primary source: press-release Microsoft to acquire GitHub for $7.5 billion, Microsoft, published 4 June 2018. Read 27 November 2026.

26 October 2018 Strain and stewardship

Microsoft completed the GitHub acquisition on 26 October 2018.

Microsoft has completed its acquisition of GitHub.

Primary source: own-post Microsoft completes GitHub acquisition, The Official Microsoft Blog, published 26 October 2018. Read 27 November 2026.

The same post says GitHub "will retain its developer-first ethos, operate independently, and remain an open platform".

3 August 2020 Strain and stewardship

In August 2020 the Linux Foundation formed the Open Source Security Foundation, folding in the Core Infrastructure Initiative; Microsoft, Google, IBM, Red Hat and GitHub were among its founding board members.

It combines efforts from the Core Infrastructure Initiative, GitHub’s Open Source Security Coalition and other open source security work from founding governing board members GitHub, Google, IBM, JPMorgan Chase, Microsoft, NCC Group, OWASP Foundation and Red Hat, among others.

Primary source: press-release Technology and Enterprise Leaders Combine Efforts to Improve Open Source Security, Open Source Security Foundation (The Linux Foundation), published 3 August 2020. Read 27 November 2026.

Connects: The Linux Foundation, Open Source Security Foundation, GitHub, Google, IBM, Microsoft, Red Hat

18 January 2024 Strain and stewardship

In his 2024 revision of "Continuous Integration", Fowler names the open source Jenkins and GitHub Actions among the usual continuous integration services.

(Examples of CI Services are tools like Jenkins, GitHub Actions, Circle CI etc.)

Primary source: own-post Continuous Integration, martinfowler.com, by Martin Fowler, published 18 January 2024. Read 27 November 2026.

Fowler does not say here that Jenkins is open source; the Jenkins project describes itself as "the leading open source automation server" on its home page.

Connects: Martin Fowler, Jenkins, GitHub

29 October 2024 Strain and stewardship

GitHub reported for 2024 more than 5.2 billion contributions to more than 518 million projects, a figure that mixes open source, public and private work.

In 2024, developers around the world made more than 5.2 billion contributions to more than 518 million open source, public, and private projects.

Primary source: report Octoverse: AI leads Python to top language as the number of global developers surges, The GitHub Blog, by GitHub Staff, published 29 October 2024. Read 27 November 2026.

GitHub's own figures; they cover private projects as well and are not a measure of open source alone.

Connects: GitHub, Octoverse

GitHub reported in October 2025 that more than 180 million developers use the platform, 36 million of whom joined in the past year.
