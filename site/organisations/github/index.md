## The facts

### 23 February 2008: GitHub added pull requests in February 2008, while the site was still in beta.

> Last night I pushed out a feature Tom and I have been talking about since day one: pull requests.

- Source (primary, own-post): [Oh yeah, there's pull requests now](https://github.blog/2008-02-23-oh-yeah-there-s-pull-requests-now/), The GitHub Blog, published 23 February 2008. Read 27 November 2026.
- Connects: GitHub, Git
- Fact id: `github-pull-requests-2008`

### 10 April 2008: GitHub launched publicly on 10 April 2008.

> GitHub is officially live. Thanks for the awesome beta everyone.

- Source (primary, own-post): [We Launched](https://github.blog/2008-04-10-we-launched/), The GitHub Blog, published 10 April 2008. Read 27 November 2026.
- Connects: GitHub
- Fact id: `github-launch-2008`

### 18 November 2015: On 18 November 2015 Microsoft released Visual Studio Code as an open source project on GitHub.

> Microsoft released Visual Studio Code beta as an open source project, available on GitHub.

- Source (primary, press-release): [Microsoft empowers developers with new and updated tools spanning Android, Azure, iOS, Linux, Office and Windows](https://news.microsoft.com/source/2015/11/18/microsoft-empowers-developers-with-new-and-updated-tools-spanning-android-azure-ios-linux-office-and-windows/), Microsoft, published 18 November 2015. Read 27 November 2026.
- Connects: Microsoft, GitHub
- Fact id: `vscode-open-source-2015`

### 4 June 2018: On 4 June 2018 Microsoft announced it would buy GitHub for $7.5 billion in stock.

> Under the terms of the agreement, Microsoft will acquire GitHub for $7.5 billion in Microsoft stock.

- Source (primary, press-release): [Microsoft to acquire GitHub for $7.5 billion](https://news.microsoft.com/2018/06/04/microsoft-to-acquire-github-for-7-5-billion/), Microsoft, published 4 June 2018. Read 27 November 2026.
- Connects: Satya Nadella, Microsoft, GitHub, Microsoft's acquisition of GitHub
- Fact id: `microsoft-github-announced-2018`

### 26 October 2018: Microsoft completed the GitHub acquisition on 26 October 2018.

> Microsoft has completed its acquisition of GitHub.

- Source (primary, own-post): [Microsoft completes GitHub acquisition](https://blogs.microsoft.com/blog/2018/10/26/microsoft-completes-github-acquisition/), The Official Microsoft Blog, published 26 October 2018. Read 27 November 2026.
- Note: The same post says GitHub "will retain its developer-first ethos, operate independently, and remain an open platform".
- Connects: Microsoft, GitHub, Microsoft's acquisition of GitHub
- Fact id: `microsoft-github-completed-2018`

### 3 August 2020: In August 2020 the Linux Foundation formed the Open Source Security Foundation, folding in the Core Infrastructure Initiative; Microsoft, Google, IBM, Red Hat and GitHub were among its founding board members.

> It combines efforts from the Core Infrastructure Initiative, GitHub’s Open Source Security Coalition and other open source security work from founding governing board members GitHub, Google, IBM, JPMorgan Chase, Microsoft, NCC Group, OWASP Foundation and Red Hat, among others.

- Source (primary, press-release): [Technology and Enterprise Leaders Combine Efforts to Improve Open Source Security](https://openssf.org/blog/2020/08/03/technology-and-enterprise-leaders-combine-efforts-to-improve-open-source-security/), Open Source Security Foundation (The Linux Foundation), published 3 August 2020. Read 27 November 2026.
- Connects: The Linux Foundation, Open Source Security Foundation, GitHub, Google, IBM, Microsoft, Red Hat
- Fact id: `openssf-founded-2020`

### 18 January 2024: In his 2024 revision of "Continuous Integration", Fowler names the open source Jenkins and GitHub Actions among the usual continuous integration services.

> (Examples of CI Services are tools like Jenkins, GitHub Actions, Circle CI etc.)

- Source (primary, own-post): [Continuous Integration](https://martinfowler.com/articles/continuousIntegration.html), martinfowler.com, published 18 January 2024. Read 27 November 2026.
- Note: Fowler does not say here that Jenkins is open source; the Jenkins project describes itself as "the leading open source automation server" on its home page.
- Connects: Martin Fowler, Jenkins, GitHub
- Fact id: `ci-services-open-source-2024`

### 29 October 2024: GitHub reported for 2024 more than 5.2 billion contributions to more than 518 million projects, a figure that mixes open source, public and private work.

> In 2024, developers around the world made more than 5.2 billion contributions to more than 518 million open source, public, and private projects.

- Source (primary, report): [Octoverse: AI leads Python to top language as the number of global developers surges](https://github.blog/news-insights/octoverse/octoverse-2024/), The GitHub Blog, published 29 October 2024. Read 27 November 2026.
- Note: GitHub's own figures; they cover private projects as well and are not a measure of open source alone.
- Connects: GitHub, Octoverse
- Fact id: `octoverse-2024`

### 19 May 2025: On 19 May 2025 Microsoft released the Windows Subsystem for Linux as open source.

> Today we’re very excited to announce the open-source release of the Windows Subsystem for Linux.

- Source (primary, own-post): [The Windows Subsystem for Linux is now open source](https://blogs.windows.com/windowsdeveloper/2025/05/19/the-windows-subsystem-for-linux-is-now-open-source/), Windows Developer Blog (Microsoft), published 19 May 2025. Read 27 November 2026.
- Connects: Microsoft, GitHub
- Fact id: `wsl-open-source-2025`

### 28 October 2025: GitHub reported in October 2025 that more than 180 million developers use the platform, 36 million of whom joined in the past year.

> Every second, more than one new developer on average joined GitHub—over 36 million in the past year. It’s our fastest absolute growth rate yet and 180 million-plus developers now work and build on GitHub.

- Source (primary, report): [Octoverse: A new developer joins GitHub every second as AI leads TypeScript to #1](https://github.blog/news-insights/octoverse/octoverse-a-new-developer-joins-github-every-second-as-ai-leads-typescript-to-1/), The GitHub Blog, published 28 October 2025. Read 27 November 2026.
- Note: GitHub's own figures for accounts on its platform.
- Connects: GitHub, Octoverse
- Fact id: `octoverse-2025`
