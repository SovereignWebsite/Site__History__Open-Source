## The facts

### 27 September 1983: On 27 September 1983 Richard Stallman announced on Usenet that he would write a complete Unix-compatible system called GNU and give it away.

> Starting this Thanksgiving I am going to write a complete Unix-compatible software system called GNU (for Gnu's Not Unix)

- Source (primary, mailing-list): [Initial Announcement (new Unix implementation)](http://www.gnu.org/gnu/initial-announcement.html), GNU Project (Free Software Foundation), published 27 September 1983. Read 27 November 2026.
- Note: The GNU Project page that hosts the text states that it was "posted by Richard Stallman on September 27, 1983". gnu.org was reachable only over http from this machine.
- Connects: Richard Stallman, GNU Project, GNU Initial Announcement, Announcement of the GNU Project
- Fact id: `gnu-announced-1983`

### March 1985: The GNU Manifesto of 1985 set out the rule that later became copyleft: anyone may modify and redistribute GNU, but nobody may restrict its further redistribution.

> Everyone will be permitted to modify and redistribute GNU, but no distributor will be allowed to restrict its further redistribution.

- Source (primary, document): [The GNU Manifesto](http://www.gnu.org/gnu/manifesto.html), GNU Project (Free Software Foundation), published 1985. Read 27 November 2026.
- Note: The month, March 1985, is given by the GNU Project's overview page ("the GNU Manifesto was published in March 1985"); the manifesto page itself says only 1985.
- Connects: Richard Stallman, GNU Project, The GNU Manifesto
- Fact id: `gnu-manifesto-1985`

### October 1985: The Free Software Foundation was founded in October 1985, at first to raise money for the development of GNU.

> The Free Software Foundation was founded in October 1985, initially to raise funds to help develop GNU.

- Source (primary, document): [Overview of the GNU System](http://www.gnu.org/gnu/gnu-history.html), GNU Project (Free Software Foundation). Read 27 November 2026.
- Connects: Free Software Foundation, GNU Project
- Fact id: `fsf-founded-1985`

### 1992: The GNU Project says that by 1990 it had every major component of its system except the kernel, and that Linux filled that gap from 1992.

> By 1990 we had either found or written all the major components except one—the kernel. Then Linux, a Unix-like kernel, was developed by Linus Torvalds in 1991 and made free software in 1992.

- Source (primary, document): [Overview of the GNU System](http://www.gnu.org/gnu/gnu-history.html), GNU Project (Free Software Foundation). Read 27 November 2026.
- Connects: Linus Torvalds, GNU Project
- Fact id: `gnu-plus-linux-1992`

### 1996: The Free Software Definition says a program is free software when its users have four essential freedoms: to run it, to study and change it, to redistribute copies and to distribute modified versions.

> A program is free software if the program's users (referred to individually here as “you”) have the four essential freedoms

- Source (primary, document): [What is Free Software? (The Free Software Definition)](http://www.gnu.org/philosophy/free-sw.html), GNU Project (Free Software Foundation). Read 27 November 2026.
- Note: The definition is a living document; the quote is from the current text. Its footnote says "Around 1990 there were three freedoms, numbered 1, 2 and 3", with freedom 0 added later, so the wording has changed over time. The date is the first copyright year on the page (1996), not the date of the idea.
- Connects: Free Software Foundation, GNU Project, The Free Software Definition
- Fact id: `four-freedoms`
