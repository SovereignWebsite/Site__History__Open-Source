## The facts

### 2005: Google has run Summer of Code, which pays new contributors to work on open source projects with mentors, since 2005.

> Since 2005, the Google Summer of Code program has connected 21,000+ new open source contributors from 123 countries with 20,000+ mentors from 138 countries.

- Source (primary, document): [About Google Summer of Code](https://summerofcode.withgoogle.com/about), Google. Read 27 November 2026.
- Note: The figures are Google's own, as shown on the programme page on the day it was read.
- Connects: Google
- Fact id: `google-summer-of-code-2005`

### 5 November 2007: On 5 November 2007 Google and the Open Handset Alliance announced Android as an open platform for mobile devices.

> A broad alliance of leading technology and wireless companies today joined forces to announce the development of Android, the first truly open and comprehensive platform for mobile devices.

- Source (primary, press-release): [Industry Leaders Announce Open Platform for Mobile Devices](https://www.openhandsetalliance.com/press_110507.html), Open Handset Alliance, published 5 November 2007. Read 27 November 2026.
- Connects: Google, Open Handset Alliance
- Fact id: `android-announced-2007`

### 21 October 2008: On 21 October 2008 Google and its partners released the Android source code.

> we and our Open Handset Alliance partners have now released the source code for Android.

- Source (primary, own-post): [Android is now Open Source](https://android-developers.googleblog.com/2008/10/android-is-now-open-source.html), Android Developers Blog (Google), published 21 October 2008. Read 27 November 2026.
- Connects: Google, Open Handset Alliance
- Fact id: `android-open-source-2008`

### 2014: The Kubernetes project states that Google open sourced it in 2014.

> Google open sourced the Kubernetes project in 2014.

- Source (primary, document): [Kubernetes documentation: Overview](https://kubernetes.io/docs/concepts/overview/), Kubernetes project. Read 27 November 2026.
- Connects: Google, Kubernetes
- Fact id: `kubernetes-google-2014`

### 3 August 2020: In August 2020 the Linux Foundation formed the Open Source Security Foundation, folding in the Core Infrastructure Initiative; Microsoft, Google, IBM, Red Hat and GitHub were among its founding board members.

> It combines efforts from the Core Infrastructure Initiative, GitHub’s Open Source Security Coalition and other open source security work from founding governing board members GitHub, Google, IBM, JPMorgan Chase, Microsoft, NCC Group, OWASP Foundation and Red Hat, among others.

- Source (primary, press-release): [Technology and Enterprise Leaders Combine Efforts to Improve Open Source Security](https://openssf.org/blog/2020/08/03/technology-and-enterprise-leaders-combine-efforts-to-improve-open-source-security/), Open Source Security Foundation (The Linux Foundation), published 3 August 2020. Read 27 November 2026.
- Connects: The Linux Foundation, Open Source Security Foundation, GitHub, Google, IBM, Microsoft, Red Hat
- Fact id: `openssf-founded-2020`
