## The facts

### 2014: The Linux Foundation founded the Core Infrastructure Initiative in response to Heartbleed, to fund critical open source projects.

> The Linux Foundation’s Core Infrastructure Initiative (CII), founded in response to the 2014 Heartbleed bug

- Source (primary, press-release): [Technology and Enterprise Leaders Combine Efforts to Improve Open Source Security](https://openssf.org/blog/2020/08/03/technology-and-enterprise-leaders-combine-efforts-to-improve-open-source-security/), Open Source Security Foundation (The Linux Foundation), published 3 August 2020. Read 27 November 2026.
- Note: Stated in the Linux Foundation's 2020 announcement of the Open Source Security Foundation; the original April 2014 press release is no longer at its address (404).
- Connects: The Linux Foundation, Open Source Security Foundation, Heartbleed
- Fact id: `core-infrastructure-initiative-2014`

### 21 July 2015: The Linux Foundation announced the Cloud Native Computing Foundation on 21 July 2015.

> The Linux Foundation, the nonprofit organization dedicated to accelerating the growth of Linux and collaborative development, today announced the Cloud Native Computing Foundation.

- Source (primary, press-release): [New Cloud Native Computing Foundation to drive alignment among container technologies](https://www.cncf.io/announcements/2015/06/21/new-cloud-native-computing-foundation-to-drive-alignment-among-container-technologies/), Cloud Native Computing Foundation (The Linux Foundation), published 21 July 2015. Read 27 November 2026.
- Connects: The Linux Foundation, Cloud Native Computing Foundation
- Fact id: `cncf-founded-2015`

### 16 November 2016: Microsoft joined the Linux Foundation as a platinum member on 16 November 2016.

> The Linux Foundation, the nonprofit advancing professional open source management for mass collaboration, today announced that Microsoft has joined the organization at a Platinum member during Microsoft’s Connect(); developer event in New York.

- Source (primary, press-release): [Microsoft Fortifies Commitment to Open Source, Becomes Linux Foundation Platinum Member](https://www.linuxfoundation.org/press/press-release/microsoft-fortifies-commitment-to-open-source-becomes-linux-foundation-platinum-member), The Linux Foundation, published 16 November 2016. Read 27 November 2026.
- Connects: Microsoft, The Linux Foundation
- Fact id: `microsoft-joins-linux-foundation-2016`

### 3 August 2020: In August 2020 the Linux Foundation formed the Open Source Security Foundation, folding in the Core Infrastructure Initiative; Microsoft, Google, IBM, Red Hat and GitHub were among its founding board members.

> It combines efforts from the Core Infrastructure Initiative, GitHub’s Open Source Security Coalition and other open source security work from founding governing board members GitHub, Google, IBM, JPMorgan Chase, Microsoft, NCC Group, OWASP Foundation and Red Hat, among others.

- Source (primary, press-release): [Technology and Enterprise Leaders Combine Efforts to Improve Open Source Security](https://openssf.org/blog/2020/08/03/technology-and-enterprise-leaders-combine-efforts-to-improve-open-source-security/), Open Source Security Foundation (The Linux Foundation), published 3 August 2020. Read 27 November 2026.
- Connects: The Linux Foundation, Open Source Security Foundation, GitHub, Google, IBM, Microsoft, Red Hat
- Fact id: `openssf-founded-2020`

### 20 September 2023: On 20 September 2023 the Linux Foundation announced OpenTofu as an open source alternative to Terraform.

> Today, the Linux Foundation announced the formation of OpenTofu, an open source alternative to Terraform's widely used infrastructure as code provisioning tool.

- Source (primary, press-release): [Linux Foundation Launches OpenTofu: A New Open Source Alternative to Terraform](https://www.linuxfoundation.org/press/announcing-opentofu), The Linux Foundation, published 20 September 2023. Read 27 November 2026.
- Note: The OpenTofu manifesto, also read, says: "we created a fork of Terraform".
- Connects: The Linux Foundation, OpenTofu, HashiCorp, Business Source License 1.1
- Fact id: `opentofu-2023`

### 28 March 2024: Eight days later the Linux Foundation announced Valkey, which continues development from Redis 7.2.4 under the BSD licence.

> Valkey will continue development on Redis 7.2.4 and will keep the project available for use and distribution under the open source Berkeley Software Distribution (BSD) 3-clause license.

- Source (primary, press-release): [Linux Foundation Launches Open Source Valkey Community](https://www.linuxfoundation.org/press/linux-foundation-launches-open-source-valkey-community), The Linux Foundation, published 28 March 2024. Read 27 November 2026.
- Connects: The Linux Foundation, Valkey, Redis, BSD licence
- Fact id: `valkey-2024`
