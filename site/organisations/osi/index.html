Open Source Initiative

Organisation founded in February 1998 by Raymond and Perens; keeper of the Open Source Definition and, since 2024, the Open Source AI Definition12.

The facts

1998 The label

Criterion 6 of the Open Source Definition forbids a licence from restricting the fields in which a program may be used, including use in a business.

The license must not restrict anyone from making use of the program in a specific field of endeavor. For example, it may not restrict the program from being used in a business, or from being used for genetic research.

Primary source: document The Open Source Definition, Open Source Initiative. Read 27 November 2026.

Quoted from the current text of the definition. This is the clause the OSI cites against licences that restrict cloud providers.

Connects: Open Source Initiative, The Open Source Definition

February 1998 The label

The Open Source Definition was made in February 1998 by revising the Debian Free Software Guidelines and removing the references to Debian.

The Open Source Definition was then created during the launch of the OSI in Feb. 1998 by revising the DFSG and removing Debian-specific references.

Primary source: document History of the OSI, Open Source Initiative. Read 27 November 2026.

February 1998 The label

Eric Raymond and Bruce Perens founded the Open Source Initiative in late February 1998.

OSI was jointly founded by Eric Raymond and Bruce Perens in late February 1998, with Raymond as its first president, Perens as vice-president

3 February 1998 The label

The Open Source Initiative's own history says the "open source" label was created at a strategy session in Palo Alto on 3 February 1998, and credits Christine Peterson with suggesting it.

The “open source” label was created at a strategy session held on February 3rd, 1998 in Palo Alto, California, shortly after the announcement of the release of the Netscape source code.

Primary source: document History of the OSI, Open Source Initiative. Read 27 November 2026.

Disputed. The OSI page gives 3 February 1998; Peterson's first-hand narrative gives 5 February 1998 (see open-source-meeting-peterson-account). The same OSI page says the term was "originally suggested by Christine Peterson".

Connects: Christine Peterson, Open Source Initiative, The strategy session that adopted "open source"

17 February 1999 The label

A year after co-founding the OSI, Bruce Perens wrote that open source had played down the freedoms of free software and that it was time to talk about free software again.

Most hackers know that Free Software and Open Source are just two words for the same thing. Unfortunately, though, Open Source has de-emphasized the importance of the freedoms involved in Free Software.

Primary source: mailing-list It's Time to Talk about Free Software Again (email to the editor, as published), LWN.net, by Bruce Perens, published 17 February 1999. Read 27 November 2026.

Read in the copy of his email of 17 February 1999 published by LWN.net; the Debian mailing-list archive presented a proof-of-work challenge and could not be read.

Connects: Bruce Perens, Open Source Initiative, It's Time to Talk about Free Software Again

16 October 2018 Strain and stewardship

On 16 October 2018 MongoDB moved its Community Server from the AGPL to a new licence of its own, the Server Side Public License.

issued a new software license, called Server Side Public License (SSPL), for MongoDB Community Server.

Primary source: press-release MongoDB Issues New Server Side Public License for MongoDB Community Server, MongoDB, Inc., published 16 October 2018. Read 27 November 2026.

The same release says MongoDB "submitted it to the Open Source Initiative for approval".

19 January 2021 Strain and stewardship

On 19 January 2021 the Open Source Initiative stated that the SSPL is not an open source licence, calling such licences "fauxpen" source.

Fauxpen source licenses allow a user to view the source code but do not allow other highly important rights protected by the Open Source Definition, such as the right to make use of the program for any field of endeavor.

Primary source: press-release The SSPL is Not an Open Source License, Open Source Initiative, published 19 January 2021. Read 27 November 2026.

Connects: Open Source Initiative, Elastic, MongoDB, Inc., Server Side Public License, The Open Source Definition

19 January 2021 Strain and stewardship

The OSI says the SSPL was submitted for its approval and then withdrawn when it became clear it would not be approved.

This license was submitted to the Open Source Initiative for approval but later withdrawn by the license steward when it became clear that the license would not be approved.

Primary source: press-release The SSPL is Not an Open Source License, Open Source Initiative, published 19 January 2021. Read 27 November 2026.

28 October 2024 Strain and stewardship

On 28 October 2024 the Open Source Initiative released version 1.0 of its Open Source AI Definition.

After a year-long, global, community design process, the Open Source Definition (OSAID) v.1.0 is available for public use.

Primary source: press-release The Open Source Initiative Announces the Release of the Industry's First Open Source AI Definition, Open Source Initiative, published 28 October 2024. Read 27 November 2026.

The release sentence says "the Open Source Definition (OSAID)"; the document released is the Open Source AI Definition.

Connects: Open Source Initiative, The Open Source AI Definition 1.0

28 October 2024 Strain and stewardship

The Open Source AI Definition requires detailed information about the training data, enough for a skilled person to build a substantially equivalent system, but not the training data itself.

Data Information: Sufficiently detailed information about the data used to train the system so that a skilled person can build a substantially equivalent system.

Primary source: document The Open Source AI Definition 1.0, Open Source Initiative, published 28 October 2024. Read 27 November 2026.

That the data itself is not required is the reading of the definition's text and is the point its critics attack; see the Software Freedom Conservancy and FSF facts.

Connects: Open Source Initiative, The Open Source AI Definition 1.0

Link to this fact

31 October 2024 Strain and stewardship

The Software Freedom Conservancy's Bradley Kuhn criticised the definition for not requiring public disclosure of training sets, and said the OSI should not have published it yet.

the OSAID fails to require reproducibility by the public of the scientific process of building these systems, because the OSAID fails to place sufficient requirements on the licensing and public disclosure of training sets

Primary source: own-post Open Source AI Definition Erodes the Meaning of "Open Source", Software Freedom Conservancy, by Bradley M. Kuhn, published 31 October 2024. Read 27 November 2026.

Connects: Software Freedom Conservancy, Open Source Initiative, The Open Source AI Definition 1.0

1 May 2025 Strain and stewardship

Redis wrote in the same post that the SSPL is not truly open source.

SSPL is not truly open source because the Open Source Initiative clarified it lacks the requisites to be an OSI-approved license.

Primary source: own-post Redis is now available under the AGPLv3 open source license, Redis, by Rowan Trollope, published 1 May 2025. Read 27 November 2026.
