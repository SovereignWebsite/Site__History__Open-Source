# Open Source Initiative

Organisation founded in February 1998 by Raymond and Perens; keeper of the Open Source Definition and, since 2024, the Open Source AI Definition [1] [2].

## The facts

### 1998: Criterion 6 of the Open Source Definition forbids a licence from restricting the fields in which a program may be used, including use in a business.

> The license must not restrict anyone from making use of the program in a specific field of endeavor. For example, it may not restrict the program from being used in a business, or from being used for genetic research.

- Source (primary, document): [The Open Source Definition](https://opensource.org/osd), Open Source Initiative. Read 27 November 2026.
- Note: Quoted from the current text of the definition. This is the clause the OSI cites against licences that restrict cloud providers.
- Connects: Open Source Initiative, The Open Source Definition
- Fact id: `osd-no-field-discrimination`

### 1998: The Open Source Definition opens by saying that open source is more than access to source code: the distribution terms must meet its ten criteria.

> Open source doesn’t just mean access to the source code. The distribution terms of open source software must comply with the following criteria:

- Source (primary, document): [The Open Source Definition](https://opensource.org/osd), Open Source Initiative. Read 27 November 2026.
- Note: Quoted from the current text of the definition (page last modified in 2024); the definition dates from 1998.
- Connects: Open Source Initiative, The Open Source Definition
- Fact id: `osd-not-just-source`

### February 1998: The Open Source Definition was made in February 1998 by revising the Debian Free Software Guidelines and removing the references to Debian.

> The Open Source Definition was then created during the launch of the OSI in Feb. 1998 by revising the DFSG and removing Debian-specific references.

- Source (primary, document): [History of the OSI](https://opensource.org/history), Open Source Initiative. Read 27 November 2026.
- Connects: Bruce Perens, Open Source Initiative, Debian Project, The Open Source Definition, Debian Free Software Guidelines
- Fact id: `osd-derived-from-dfsg-1998`

### February 1998: Eric Raymond and Bruce Perens founded the Open Source Initiative in late February 1998.

> OSI was jointly founded by Eric Raymond and Bruce Perens in late February 1998, with Raymond as its first president, Perens as vice-president

- Source (primary, document): [History of the OSI](https://opensource.org/history), Open Source Initiative. Read 27 November 2026.
- Connects: Eric S. Raymond, Bruce Perens, Open Source Initiative
- Fact id: `osi-founded-1998`

### 3 February 1998: The Open Source Initiative's own history says the "open source" label was created at a strategy session in Palo Alto on 3 February 1998, and credits Christine Peterson with suggesting it.

> The “open source” label was created at a strategy session held on February 3rd, 1998 in Palo Alto, California, shortly after the announcement of the release of the Netscape source code.

- Source (primary, document): [History of the OSI](https://opensource.org/history), Open Source Initiative. Read 27 November 2026.
- Note: Disputed. The OSI page gives 3 February 1998; Peterson's first-hand narrative gives 5 February 1998 (see open-source-meeting-peterson-account). The same OSI page says the term was "originally suggested by Christine Peterson".
- Connects: Christine Peterson, Open Source Initiative, The strategy session that adopted "open source"
- Fact id: `open-source-label-osi-account`

### 17 February 1999: A year after co-founding the OSI, Bruce Perens wrote that open source had played down the freedoms of free software and that it was time to talk about free software again.

> Most hackers know that Free Software and Open Source are just two words for the same thing. Unfortunately, though, Open Source has de-emphasized the importance of the freedoms involved in Free Software.

- Source (primary, mailing-list): [It's Time to Talk about Free Software Again (email to the editor, as published)](https://static.lwn.net/1999/0218/a/bp.html), LWN.net, published 17 February 1999. Read 27 November 2026.
- Note: Read in the copy of his email of 17 February 1999 published by LWN.net; the Debian mailing-list archive presented a proof-of-work challenge and could not be read.
- Connects: Bruce Perens, Open Source Initiative, It's Time to Talk about Free Software Again
- Fact id: `perens-free-software-again-1999`

### 17 February 1999: In the same message Perens said he would go on promoting software that fits the Open Source Definition, but independently of the Open Source Initiative.

> I'll be working to promote software that fits that definition, but independently from the Open Source Initiative.

- Source (primary, mailing-list): [It's Time to Talk about Free Software Again (email to the editor, as published)](https://static.lwn.net/1999/0218/a/bp.html), LWN.net, published 17 February 1999. Read 27 November 2026.
- Connects: Bruce Perens, Eric S. Raymond, Open Source Initiative, It's Time to Talk about Free Software Again
- Fact id: `perens-leaves-osi-1999`

### 2018: MongoDB's own FAQ states that the SSPL has not been approved by the Open Source Initiative.

> The SSPL has not been approved by the OSI.

- Source (primary, document): [Server Side Public License FAQ](https://www.mongodb.com/legal/licensing/server-side-public-license/faq), MongoDB, Inc.. Read 27 November 2026.
- Note: The FAQ is undated; it is dated here to the year the licence was issued.
- Connects: MongoDB, Inc., Open Source Initiative, Server Side Public License
- Fact id: `sspl-not-osi-approved`

### 16 October 2018: On 16 October 2018 MongoDB moved its Community Server from the AGPL to a new licence of its own, the Server Side Public License.

> issued a new software license, called Server Side Public License (SSPL), for MongoDB Community Server.

- Source (primary, press-release): [MongoDB Issues New Server Side Public License for MongoDB Community Server](https://www.mongodb.com/company/newsroom/press-releases/mongodb-issues-new-server-side-public-license-for-mongodb-community-server), MongoDB, Inc., published 16 October 2018. Read 27 November 2026.
- Note: The same release says MongoDB "submitted it to the Open Source Initiative for approval".
- Connects: MongoDB, Inc., Open Source Initiative, Server Side Public License
- Fact id: `mongodb-sspl-2018`

### 19 January 2021: On 19 January 2021 the Open Source Initiative stated that the SSPL is not an open source licence, calling such licences "fauxpen" source.

> Fauxpen source licenses allow a user to view the source code but do not allow other highly important rights protected by the Open Source Definition, such as the right to make use of the program for any field of endeavor.

- Source (primary, press-release): [The SSPL is Not an Open Source License](https://opensource.org/blog/the-sspl-is-not-an-open-source-license), Open Source Initiative, published 19 January 2021. Read 27 November 2026.
- Connects: Open Source Initiative, Elastic, MongoDB, Inc., Server Side Public License, The Open Source Definition
- Fact id: `osi-sspl-not-open-source-2021`

### 19 January 2021: The OSI says the SSPL was submitted for its approval and then withdrawn when it became clear it would not be approved.

> This license was submitted to the Open Source Initiative for approval but later withdrawn by the license steward when it became clear that the license would not be approved.

- Source (primary, press-release): [The SSPL is Not an Open Source License](https://opensource.org/blog/the-sspl-is-not-an-open-source-license), Open Source Initiative, published 19 January 2021. Read 27 November 2026.
- Connects: Open Source Initiative, MongoDB, Inc., Server Side Public License
- Fact id: `osi-sspl-withdrawn`

### 2 February 2024: The Open Source Initiative welcomed the final text in February 2024, noting the new "open source steward" role.

> It also creates a new form of economic actor, the “open source steward,” which acknowledges the role played by foundations and platforms in the open source ecosystem.

- Source (primary, own-post): [The European regulators listened to the Open Source communities!](https://opensource.org/blog/the-european-regulators-listened-to-the-open-source-communities), Open Source Initiative, published 2 February 2024. Read 27 November 2026.
- Connects: Open Source Initiative, European Union, Cyber Resilience Act (Regulation (EU) 2024/2847)
- Fact id: `osi-on-cra-2024`

### 29 August 2024: On 29 August 2024 Shay Banon of Elastic announced that Elasticsearch and Kibana would also be offered under the AGPL, an OSI-approved licence.

> The tl;dr is that we will be adding AGPL as another license option next to ELv2 and SSPL in the coming weeks.

- Source (primary, own-post): [Elasticsearch is open source, again](https://www.elastic.co/blog/elasticsearch-is-open-source-again), Elastic, published 29 August 2024. Read 27 November 2026.
- Connects: Shay Banon, Elastic, Open Source Initiative
- Fact id: `elastic-agpl-2024`

### 29 August 2024: Banon wrote that using an OSI-approved licence was what allowed Elastic to use the term "open source" again.

> But being able to use the term Open Source, by using AGPL, an OSI approved license, removes any questions, or fud, people might have.

- Source (primary, own-post): [Elasticsearch is open source, again](https://www.elastic.co/blog/elasticsearch-is-open-source-again), Elastic, published 29 August 2024. Read 27 November 2026.
- Connects: Shay Banon, Elastic, Open Source Initiative
- Fact id: `elastic-open-source-again-2024`

### 28 October 2024: On 28 October 2024 the Open Source Initiative released version 1.0 of its Open Source AI Definition.

> After a year-long, global, community design process, the Open Source Definition (OSAID) v.1.0 is available for public use.

- Source (primary, press-release): [The Open Source Initiative Announces the Release of the Industry's First Open Source AI Definition](https://opensource.org/blog/the-open-source-initiative-announces-the-release-of-the-industrys-first-open-source-ai-definition), Open Source Initiative, published 28 October 2024. Read 27 November 2026.
- Note: The release sentence says "the Open Source Definition (OSAID)"; the document released is the Open Source AI Definition.
- Connects: Open Source Initiative, The Open Source AI Definition 1.0
- Fact id: `osaid-1-0-2024`

### 28 October 2024: The Open Source AI Definition requires detailed information about the training data, enough for a skilled person to build a substantially equivalent system, but not the training data itself.

> Data Information: Sufficiently detailed information about the data used to train the system so that a skilled person can build a substantially equivalent system.

- Source (primary, document): [The Open Source AI Definition 1.0](https://opensource.org/ai/open-source-ai-definition), Open Source Initiative, published 28 October 2024. Read 27 November 2026.
- Note: That the data itself is not required is the reading of the definition's text and is the point its critics attack; see the Software Freedom Conservancy and FSF facts.
- Connects: Open Source Initiative, The Open Source AI Definition 1.0
- Fact id: `osaid-data-information`

### 31 October 2024: The Software Freedom Conservancy's Bradley Kuhn criticised the definition for not requiring public disclosure of training sets, and said the OSI should not have published it yet.

> the OSAID fails to require reproducibility by the public of the scientific process of building these systems, because the OSAID fails to place sufficient requirements on the licensing and public disclosure of training sets

- Source (primary, own-post): [Open Source AI Definition Erodes the Meaning of "Open Source"](https://sfconservancy.org/blog/2024/oct/31/open-source-ai-definition-osaid-erodes-foss/), Software Freedom Conservancy, published 31 October 2024. Read 27 November 2026.
- Connects: Software Freedom Conservancy, Open Source Initiative, The Open Source AI Definition 1.0
- Fact id: `sfc-osaid-criticism-2024`

- Source (primary, own-post): [Redis is now available under the AGPLv3 open source license](https://redis.io/blog/agplv3/), Redis, published 1 May 2025. Read 27 November 2026.
