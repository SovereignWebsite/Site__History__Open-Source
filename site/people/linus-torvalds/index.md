## The facts

### 25 August 1991: On 25 August 1991 Linus Torvalds told the comp.os.minix newsgroup that he was writing a free operating system as a hobby.

> I'm doing a (free) operating system (just a hobby, won't be big and professional like gnu) for 386(486) AT clones.

- Source (primary, archive): [Linux History (compilation of early Usenet posts on comp.os.minix)](https://www.cs.cmu.edu/~awb/linux.history.html), Carnegie Mellon University School of Computer Science (personal page), published 25 August 1991. Read 27 November 2026.
- Note: Read in a compilation of the Usenet posts hosted at Carnegie Mellon University, which shows the header "Date: 25 Aug 91 20:57:08 GMT". The original is a Usenet post; Google Groups could not be fetched as text.
- Connects: Linus Torvalds
- Fact id: `linus-minix-post-1991`

### 1992: The GNU Project says that by 1990 it had every major component of its system except the kernel, and that Linux filled that gap from 1992.

> By 1990 we had either found or written all the major components except one—the kernel. Then Linux, a Unix-like kernel, was developed by Linus Torvalds in 1991 and made free software in 1992.

- Source (primary, document): [Overview of the GNU System](http://www.gnu.org/gnu/gnu-history.html), GNU Project (Free Software Foundation). Read 27 November 2026.
- Connects: Linus Torvalds, GNU Project
- Fact id: `gnu-plus-linux-1992`

### 1992: In the release notes for Linux 0.12 Torvalds announced that the kernel would move to the GNU copyleft, dropping his earlier ban on distributing it for money.

> The Linux copyright will change: I've had a couple of requests to make it compatible with the GNU copyleft, removing the "you may not distribute it for money" condition. I agree.

- Source (primary, document): [Release notes for Linux v0.12](https://www.kernel.org/pub/linux/kernel/Historic/old-versions/RELNOTES-0.12), kernel.org (Historic old versions). Read 27 November 2026.
- Note: The release notes say the GNU copyleft "takes effect as of the first of February" but carry no year; 1992 is from the GNU Project overview, which says Linux was "made free software in 1992".
- Connects: Linus Torvalds, GNU General Public License
- Fact id: `linux-gpl-1992`

### May 1997: Eric Raymond's essay "The Cathedral and the Bazaar", first presented in May 1997, contrasted closed "cathedral" development with the open "bazaar" style of Linux.

> I discuss these theories in terms of two fundamentally different development styles, the ``cathedral'' model of most of the commercial world versus the ``bazaar'' model of the Linux world.

- Source (primary, document): [The Cathedral and the Bazaar (title page, revision history and abstract)](http://catb.org/~esr/writings/cathedral-bazaar/cathedral-bazaar/index.html), Eric S. Raymond (catb.org), published May 1997. Read 27 November 2026.
- Note: The date is from the essay's revision history, which records the first official presentation at the Linux Kongress in May 1997. The text read is version 3.0 (2000). www.catb.org did not answer; catb.org over http did.
- Connects: Eric S. Raymond, Linus Torvalds, The Cathedral and the Bazaar
- Fact id: `cathedral-bazaar-1997`

### May 1997: Raymond coined "Linus's Law": given enough eyeballs, all bugs are shallow.

> Or, less formally, ``Given enough eyeballs, all bugs are shallow.'' I dub this: ``Linus's Law''.

- Source (primary, document): [The Cathedral and the Bazaar: Release Early, Release Often](http://catb.org/~esr/writings/cathedral-bazaar/cathedral-bazaar/ar01s04.html), Eric S. Raymond (catb.org), published May 1997. Read 27 November 2026.
- Note: The wording and the name are Raymond's, not Torvalds's. Text read is version 3.0 of the essay.
- Connects: Eric S. Raymond, Linus Torvalds, The Cathedral and the Bazaar
- Fact id: `linuss-law-1997`

### May 1997: Lesson 7 of "The Cathedral and the Bazaar" is to release early, release often and listen to your customers, which Raymond drew from how Torvalds ran Linux.

> 7. Release early. Release often. And listen to your customers.

- Source (primary, document): [The Cathedral and the Bazaar: Release Early, Release Often](http://catb.org/~esr/writings/cathedral-bazaar/cathedral-bazaar/ar01s04.html), Eric S. Raymond (catb.org), published May 1997. Read 27 November 2026.
- Note: Text read is version 3.0 of the essay (2000); the lesson is commonly cited from the 1997 original.
- Connects: Eric S. Raymond, Linus Torvalds, The Cathedral and the Bazaar
- Fact id: `release-early-release-often`

### 2005: Git was created in 2005 by Linus Torvalds and the Linux kernel community after they lost free use of the proprietary BitKeeper tool.

> In 2005, the relationship between the community that developed the Linux kernel and the commercial company that developed BitKeeper broke down, and the tool’s free-of-charge status was revoked. This prompted the Linux development community (and in particular Linus Torvalds, the creator of Linux) to develop their own tool

- Source (secondary, book): [Pro Git, 1.2 Getting Started: A Short History of Git](https://git-scm.com/book/en/v2/Getting-Started-A-Short-History-of-Git), git-scm.com (Apress). Read 27 November 2026.
- Note: From the Pro Git book hosted on the Git project's site. Torvalds's own 2005 messages on lore.kernel.org were behind a bot challenge and could not be read.
- Connects: Linus Torvalds, Git
- Fact id: `git-created-2005`

### 2005: The README in the first revision of Git describes it as a stupid but extremely fast directory content manager.

> This is a stupid (but extremely fast) directory content manager. It doesn't do a whole lot, but what it _does_ do is track directory contents efficiently.

- Source (primary, document): [README in the initial revision of git (commit e83c5163)](https://raw.githubusercontent.com/git/git/e83c5163316f89bfbde7d9ab23ca2e25604af290/README), git project (GitHub mirror), published 2005. Read 27 November 2026.
- Note: The README is read from the first commit in the Git repository (e83c5163); the file itself carries no date, so only the year is given.
- Connects: Linus Torvalds, Git
- Fact id: `git-first-readme-2005`
