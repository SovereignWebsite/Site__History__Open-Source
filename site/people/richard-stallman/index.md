## The facts

### 1971: Richard Stallman recalls joining the MIT Artificial Intelligence Lab in 1971 and finding a community in which sharing software was the normal practice.

> I became part of a software-sharing community that had existed for many years. Sharing of software was not limited to our particular community; it is as old as computers, just as sharing of recipes is as old as cooking.

- Source (primary, own-post): [The GNU Project](http://www.gnu.org/gnu/thegnuproject.html), GNU Project (Free Software Foundation), published 1998. Read 27 November 2026.
- Note: This is Stallman's own later recollection (essay first published in 1998), not a document from 1971.
- Connects: Richard Stallman, MIT Artificial Intelligence Lab
- Fact id: `stallman-sharing-community-1971`

### 27 September 1983: On 27 September 1983 Richard Stallman announced on Usenet that he would write a complete Unix-compatible system called GNU and give it away.

> Starting this Thanksgiving I am going to write a complete Unix-compatible software system called GNU (for Gnu's Not Unix)

- Source (primary, mailing-list): [Initial Announcement (new Unix implementation)](http://www.gnu.org/gnu/initial-announcement.html), GNU Project (Free Software Foundation), published 27 September 1983. Read 27 November 2026.
- Note: The GNU Project page that hosts the text states that it was "posted by Richard Stallman on September 27, 1983". gnu.org was reachable only over http from this machine.
- Connects: Richard Stallman, GNU Project, GNU Initial Announcement, Announcement of the GNU Project
- Fact id: `gnu-announced-1983`

### 27 September 1983: Stallman gave an ethical reason for GNU: he held that sharing programs is a duty and refused to sign nondisclosure or software licence agreements.

> I consider that the golden rule requires that if I like a program I must share it with other people who like it. I cannot in good conscience sign a nondisclosure agreement or a software license agreement.

- Source (primary, mailing-list): [Initial Announcement (new Unix implementation)](http://www.gnu.org/gnu/initial-announcement.html), GNU Project (Free Software Foundation), published 27 September 1983. Read 27 November 2026.
- Connects: Richard Stallman, GNU Initial Announcement
- Fact id: `gnu-golden-rule-1983`

### March 1985: The GNU Manifesto of 1985 set out the rule that later became copyleft: anyone may modify and redistribute GNU, but nobody may restrict its further redistribution.

> Everyone will be permitted to modify and redistribute GNU, but no distributor will be allowed to restrict its further redistribution.

- Source (primary, document): [The GNU Manifesto](http://www.gnu.org/gnu/manifesto.html), GNU Project (Free Software Foundation), published 1985. Read 27 November 2026.
- Note: The month, March 1985, is given by the GNU Project's overview page ("the GNU Manifesto was published in March 1985"); the manifesto page itself says only 1985.
- Connects: Richard Stallman, GNU Project, The GNU Manifesto
- Fact id: `gnu-manifesto-1985`

### 1989: Stallman describes copyleft, the method behind the GNU General Public License, as using copyright law to keep a program free.

> Copyleft uses copyright law, but flips it over to serve the opposite of its usual purpose: instead of a means for restricting a program, it becomes a means for keeping the program free.

- Source (primary, own-post): [The GNU Project](http://www.gnu.org/gnu/thegnuproject.html), GNU Project (Free Software Foundation), published 1998. Read 27 November 2026.
- Note: The explanation is from Stallman's 1998 essay; it is dated here to the first GPL (1989), the licence that implements it.
- Connects: Richard Stallman, GNU General Public License
- Fact id: `copyleft-defined`

### 1998: Richard Stallman describes 1998 as the year part of the free software community splintered off to campaign under the name "open source".

> In 1998, a part of the free software community splintered off and began campaigning in the name of “open source.”

- Source (primary, own-post): [Why Open Source Misses the Point of Free Software](http://www.gnu.org/philosophy/open-source-misses-the-point.html), GNU Project (Free Software Foundation), published 2007. Read 27 November 2026.
- Note: From Stallman's essay, whose copyright notice begins in 2007.
- Connects: Richard Stallman, Why Open Source Misses the Point of Free Software
- Fact id: `stallman-1998-splinter`

### November 2006: In November 2006 Sun Microsystems committed to releasing Java under the GPL, a move the Free Software Foundation welcomed.

> The Free Software Foundation (FSF) welcomed the public commitment from Sun Microsystems to distribute its proprietary Java platform under the GNU General Public License (GPL)

- Source (primary, press-release): [Sun begins releasing Java under the GPL](https://www.fsf.org/news/fsf-welcomes-gpl-java.html), Free Software Foundation, published 15 November 2006. Read 27 November 2026.
- Note: This is the FSF's press release of 15 November 2006, primary for the FSF's reaction and second-hand for Sun's announcement; Sun's own release (13 November 2006 by other accounts) is no longer online and could not be fetched.
- Connects: Richard Stallman, Sun Microsystems, Free Software Foundation, GNU General Public License
- Fact id: `sun-java-gpl-2006`

### 2007: Stallman's position is that free software is a movement for users' freedom while open source values mainly practical advantage, and that the GNU Project therefore does not use the term "open source".

> The free software movement campaigns for freedom for the users of computing; it is a movement for freedom and justice. By contrast, the open source idea values mainly practical advantage and does not campaign for principles. This is why we do not agree with open source, and do not use that term.

- Source (primary, own-post): [Why Open Source Misses the Point of Free Software](http://www.gnu.org/philosophy/open-source-misses-the-point.html), GNU Project (Free Software Foundation), published 2007. Read 27 November 2026.
- Note: Dated to the first copyright year of the essay (2007); the essay has been revised since and the current text was read.
- Connects: Richard Stallman, Free Software Foundation, Why Open Source Misses the Point of Free Software
- Fact id: `stallman-open-source-misses-point`

### 29 June 2007: The Free Software Foundation released version 3 of the GPL on 29 June 2007, adding protection against locked-down devices and an explicit patent licence.

> Version 3 of the GNU GPL strengthens this guarantee, by ensuring that users can modify the free software on their personal and household devices, and granting patent licenses to every user.

- Source (primary, press-release): [FSF releases the GNU General Public License, version 3](https://www.fsf.org/news/gplv3_launched), Free Software Foundation, published 29 June 2007. Read 27 November 2026.
- Connects: Richard Stallman, Free Software Foundation, GNU General Public License
- Fact id: `gplv3-released-2007`
