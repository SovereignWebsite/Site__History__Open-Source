Satya Nadella

Chief executive of Microsoft from February 2014, who presented the "Microsoft loves Linux" slide that October12.

The facts

4 February 2014 Mainstream

Microsoft's board appointed Satya Nadella chief executive on 4 February 2014.

Microsoft Corp. today announced that its Board of Directors has appointed Satya Nadella as Chief Executive Officer and member of the Board of Directors effective immediately.

Primary source: press-release Microsoft Board names Satya Nadella as CEO, Microsoft, published 4 February 2014. Read 27 November 2026.

The Register's report of October 2014, also read, calls him "Steve Ballmer's successor".

Connects: Satya Nadella, Microsoft

20 October 2014 Mainstream

At the same event Nadella said about a fifth of Azure was running Linux.

About 20 percent of the workloads run on Azure are based on Linux, Nadella admitted.

Secondary source: reporting Microsoft (hearts) Linux, for Azure's sake, PCWorld (IDG News Service), by Joab Jackson, published 20 October 2014. Read 27 November 2026.

Usually paraphrased. A reporter's summary, not a direct quotation. The Register's report says "20 per cent of Microsoft's Azure cloud is already Linux"; the two reports differ on whether the figure is workloads or the cloud as a whole.

Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco

Link to this fact

20 October 2014 Mainstream

At a cloud event for the press in San Francisco on 20 October 2014, Satya Nadella delivered the message "Microsoft loves Linux".

"Microsoft loves Linux" is generally not something one expects to hear, but that was one of the messages that Microsoft CEO Satya Nadella delivered at a San Francisco media event touting Redmond's cloud offerings on Monday.

Secondary source: reporting Redmond top man Satya Nadella: 'Microsoft LOVES Linux', The Register, by Neil McAllister, published 21 October 2014. Read 27 November 2026.

The best records found are press reports by reporters at the event (The Register, PCWorld) and Microsoft's own later acknowledgement of the slide (May 2015). No Microsoft transcript or press release of 20 October 2014 containing the phrase was found.

Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco

20 October 2014 Mainstream

PCWorld reported that Nadella stood in front of an image reading "Microsoft [heart] Linux" during the webcast.

This was the message from Microsoft CEO Satya Nadella, standing in front of an image that read “Microsoft [heart symbol] Linux,” during a Monday webcast

Secondary source: reporting Microsoft (hearts) Linux, for Azure's sake, PCWorld (IDG News Service), by Joab Jackson, published 20 October 2014. Read 27 November 2026.

The slide used a heart symbol, so "Microsoft loves Linux" is the spoken reading of it. "[heart symbol]" is PCWorld's own wording.

Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco

6 May 2015 Mainstream

Microsoft's Windows Server team confirmed the slide in its own blog post in May 2015.

In a press and analyst briefing a few months back, Microsoft CEO Satya Nadella put up a slide proclaiming “Microsoft ♥ Linux”.

Primary source: own-post Microsoft Loves Linux, Microsoft (Windows Server blog), by Microsoft Windows Server Team, published 6 May 2015. Read 27 November 2026.

Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco

4 June 2018 Strain and stewardship

On 4 June 2018 Microsoft announced it would buy GitHub for $7.5 billion in stock.

Under the terms of the agreement, Microsoft will acquire GitHub for $7.5 billion in Microsoft stock.

Primary source: press-release Microsoft to acquire GitHub for $7.5 billion, Microsoft, published 4 June 2018. Read 27 November 2026.

Connects: Satya Nadella, Microsoft, GitHub, Microsoft's acquisition of GitHub
