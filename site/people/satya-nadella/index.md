## The facts

### 4 February 2014: Microsoft's board appointed Satya Nadella chief executive on 4 February 2014.

> Microsoft Corp. today announced that its Board of Directors has appointed Satya Nadella as Chief Executive Officer and member of the Board of Directors effective immediately.

- Source (primary, press-release): [Microsoft Board names Satya Nadella as CEO](https://news.microsoft.com/2014/02/04/microsoft-board-names-satya-nadella-as-ceo/), Microsoft, published 4 February 2014. Read 27 November 2026.
- Note: The Register's report of October 2014, also read, calls him "Steve Ballmer's successor".
- Connects: Satya Nadella, Microsoft
- Fact id: `nadella-ceo-2014`

### 20 October 2014: At the same event Nadella said about a fifth of Azure was running Linux.

> About 20 percent of the workloads run on Azure are based on Linux, Nadella admitted.

- Source (secondary, reporting): [Microsoft (hearts) Linux, for Azure's sake](https://www.pcworld.com/article/435928/microsoft-hearts-linux-for-azures-sake.html), PCWorld (IDG News Service), published 20 October 2014. Read 27 November 2026.
- Note: Usually paraphrased. A reporter's summary, not a direct quotation. The Register's report says "20 per cent of Microsoft's Azure cloud is already Linux"; the two reports differ on whether the figure is workloads or the cloud as a whole.
- Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco
- Fact id: `azure-linux-share-2014`

### 20 October 2014: At a cloud event for the press in San Francisco on 20 October 2014, Satya Nadella delivered the message "Microsoft loves Linux".

> "Microsoft loves Linux" is generally not something one expects to hear, but that was one of the messages that Microsoft CEO Satya Nadella delivered at a San Francisco media event touting Redmond's cloud offerings on Monday.

- Source (secondary, reporting): [Redmond top man Satya Nadella: 'Microsoft LOVES Linux'](https://www.theregister.com/2014/10/20/microsoft_cloud_event/), The Register, published 21 October 2014. Read 27 November 2026.
- Note: The best records found are press reports by reporters at the event (The Register, PCWorld) and Microsoft's own later acknowledgement of the slide (May 2015). No Microsoft transcript or press release of 20 October 2014 containing the phrase was found.
- Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco
- Fact id: `microsoft-loves-linux-2014`

### 20 October 2014: PCWorld reported that Nadella stood in front of an image reading "Microsoft [heart] Linux" during the webcast.

> This was the message from Microsoft CEO Satya Nadella, standing in front of an image that read “Microsoft [heart symbol] Linux,” during a Monday webcast

- Source (secondary, reporting): [Microsoft (hearts) Linux, for Azure's sake](https://www.pcworld.com/article/435928/microsoft-hearts-linux-for-azures-sake.html), PCWorld (IDG News Service), published 20 October 2014. Read 27 November 2026.
- Note: The slide used a heart symbol, so "Microsoft loves Linux" is the spoken reading of it. "[heart symbol]" is PCWorld's own wording.
- Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco
- Fact id: `microsoft-loves-linux-slide-2014`

### 6 May 2015: Microsoft's Windows Server team confirmed the slide in its own blog post in May 2015.

> In a press and analyst briefing a few months back, Microsoft CEO Satya Nadella put up a slide proclaiming “Microsoft ♥ Linux”.

- Source (primary, own-post): [Microsoft Loves Linux](https://www.microsoft.com/en-us/windows-server/blog/2015/05/06/microsoft-loves-linux), Microsoft (Windows Server blog), published 6 May 2015. Read 27 November 2026.
- Connects: Satya Nadella, Microsoft, Microsoft cloud event, San Francisco
- Fact id: `microsoft-loves-linux-acknowledged-2015`

### 4 June 2018: On 4 June 2018 Microsoft announced it would buy GitHub for $7.5 billion in stock.

> Under the terms of the agreement, Microsoft will acquire GitHub for $7.5 billion in Microsoft stock.

- Source (primary, press-release): [Microsoft to acquire GitHub for $7.5 billion](https://news.microsoft.com/2018/06/04/microsoft-to-acquire-github-for-7-5-billion/), Microsoft, published 4 June 2018. Read 27 November 2026.
- Connects: Satya Nadella, Microsoft, GitHub, Microsoft's acquisition of GitHub
- Fact id: `microsoft-github-announced-2018`
