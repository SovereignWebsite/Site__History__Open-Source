Ward Cunningham

Programmer who created the first wiki in 1995 and is an author of the Agile Manifesto12.

The facts

1995 Free software

Cunningham confirmed in correspondence with a dictionary editor that he named the technology WikiWikiWeb in 1995, after the Hawaiian word for quick.

I chose to call the technology WikiWikiWeb.

Primary source: own-post Correspondence on the Etymology of Wiki, Cunningham & Cunningham, Inc. (c2.com), by Ward Cunningham, published November 2003. Read 27 November 2026.

In the same reply, asked "In 1995?", he answers "Yes."

Connects: Ward Cunningham, WikiWikiWeb

25 March 1995 Free software

Ward Cunningham started the first wiki, the WikiWikiWeb, on 25 March 1995 as a supplement to the Portland Pattern Repository.

This is the first ever wiki site, founded as an automated supplement to the PortlandPatternRepository.

Primary source: archive WikiHistory (page of the original wiki, WikiWikiWeb), Cunningham & Cunningham, Inc. (c2.com), by Ward Cunningham and wiki contributors. Read 27 November 2026.

From the WikiHistory page of the original wiki, read from the site's page data (JSON). The page opens "This began on March 25, 1995." and continues in the first person ("I created the site"); it is a wiki page and so could have been edited by others.

Connects: Ward Cunningham, WikiWikiWeb

February 2001 Hostility and adoption

The authors of the Agile Manifesto include Kent Beck (JUnit), Ward Cunningham (the first wiki) and Martin Fowler (who wrote on open source as a method).

Kent Beck [...] Ward Cunningham Martin Fowler

Primary source: document Manifesto for Agile Software Development, agilemanifesto.org, by The seventeen authors, published February 2001. Read 27 November 2026.

Connects: Kent Beck, Ward Cunningham, Martin Fowler, Manifesto for Agile Software Development

February 2001 Hostility and adoption

The Manifesto for Agile Software Development carries a notice that it may be freely copied in any form, but only in its entirety.

© 2001, the above authors this declaration may be freely copied in any form, but only in its entirety through this notice.

Primary source: document Manifesto for Agile Software Development, agilemanifesto.org, by The seventeen authors, published February 2001. Read 27 November 2026.

This permits verbatim copying only, so it is not an open source or free culture licence; the parallel is in the wish to be copied.

Connects: Kent Beck, Ward Cunningham, Martin Fowler, Manifesto for Agile Software Development

2026 Strain and stewardship

Cunningham's later project, the Smallest Federated Wiki, is published on GitHub under the MIT licence or the GPL version 2.

You may use the Smallest Federated Wiki under either the

Primary source: document Smallest Federated Wiki: ReadMe, GitHub (WardCunningham/Smallest-Federated-Wiki), by Ward Cunningham and contributors. Read 27 November 2026.

The sentence continues with links to the "MIT License" or the "GNU General Public License" "(GPL) Version 2". The ReadMe carries no date and GitHub's API refused the request for the repository's creation date, so the fact is dated to the year it was read; the project is older.

Connects: Ward Cunningham, GitHub
