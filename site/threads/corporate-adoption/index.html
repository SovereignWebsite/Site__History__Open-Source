Corporate adoption

How companies went from tolerating open source to building their businesses on it, and then to buying its institutions.

  1. February 1995 Free software

    Webmasters pool their patches and create the dominant web server.

    The Apache Group formed in February 1995, when eight webmasters began co-ordinating their patches to the NCSA web server.

    By the end of February, eight core contributors formed the foundation of the original Apache Group

    Primary source: document About the Apache HTTP Server Project, The Apache Software Foundation. Read 27 November 2026.

    Connects: Brian Behlendorf, Apache Group and Apache Software Foundation

    Link to this fact

  2. 22 January 1998 The label

    A listed company opens its main product.

    On 22 January 1998 Netscape announced that it would publish the source code of the next generation of its Communicator browser.

    MOUNTAIN VIEW, Calif. (January 22, 1998) — Netscape Communications Corporation (NASDAQ: NSCP) today announced bold plans to make the source code for the next generation of its highly popular Netscape Communicator client software available for free licensing on the Internet.

    Primary source: press-release January 22, 1998: the Beginning of Mozilla (reproduces the Netscape press release in full), Mitchell Baker's blog (Lizard Wrangling), by Mitchell Baker; Netscape Communications Corporation, published 22 January 1998. Read 27 November 2026.

    The press release is read as reproduced in full by Mitchell Baker (later chair of Mozilla) on her blog in 2008. The same opening paragraph was forwarded to the Linux kernel mailing list on 22 January 1998. The Netscape original survives only in the Internet Archive, which could not be reached from this machine.

    Connects: Netscape Communications, Netscape source code announcement

    Link to this fact

  3. 1999 The label

    A Linux distributor becomes a public company.

    Red Hat, a Linux distributor, became a public company in 1999.

    When Red Hat went public in 1999 with a record-setting IPO, this newsworthy success validated Red Hat’s unwavering belief and trust in the power of open source.

    Primary source: document Red Hat brand standards: History, Red Hat. Read 27 November 2026.

    From Red Hat's own history page; "record-setting" is the company's description and the page gives no figure.

    Connects: Red Hat

    Link to this fact

    Apache incorporates as a foundation.

    On 30 June 1999 the Apache Group announced that it had incorporated as the Apache Software Foundation.

    The Apache Group today announced the creation of the Apache Software Foundation (ASF), to formally shepherd the development of the #1 Web server worldwide

    Primary source: press-release The Apache Group incorporates to become the Apache Software Foundation, The Apache Software Foundation, published 30 June 1999. Read 27 November 2026.

    Connects: Apache Group and Apache Software Foundation

  5. 19 July 2000 The label

    Sun opens its office suite.

    On 19 July 2000 Sun Microsystems announced it would release the StarOffice source code under the GPL, creating OpenOffice.org.

    Sun Microsystems, Inc. announced it will release the source code of its StarOffice (TM) Suite, a leading, high quality, office productivity application software suite, to the open source community under the GNU General Public License (GPL).

    Primary source: press-release Sun Microsystems Open Sources StarOffice Technology, Sun Microsystems (hosted by OpenOffice.org), published 19 July 2000. Read 27 November 2026.

    Connects: Sun Microsystems, GNU General Public License

  6. 12 December 2000 The label

    IBM commits $1 billion to Linux.

    In December 2000 IBM's chief executive, Lou Gerstner, said IBM would spend $1 billion on Linux in 2001.

    Chief executive Louis Gerstner says Big Blue will spend $1 billion on Linux next year

    Secondary source: reporting IBM to spend $1 billion on Linux in 2001, CNET, by CNET staff, published 12 December 2000. Read 27 November 2026.

    Reported by CNET on 12 December 2000 from Gerstner's speech at the eBusiness Conference and Expo in New York. No IBM transcript of the speech was found.

    The Mozilla Foundation released Firefox 1.0 on 9 November 2004.

    The Mozilla Foundation, a non-profit organization dedicated to preserving choice and promoting innovation on the Internet, today announced the worldwide availability of the Mozilla Firefox 1.0 web browser.

    Primary source: press-release Mozilla Foundation releases the highly anticipated Mozilla Firefox 1.0 web browser, Mozilla Foundation, published 9 November 2004. Read 27 November 2026.

  8. 2005 Hostility and adoption

    The kernel developers build their own version control tool.

    Git was created in 2005 by Linus Torvalds and the Linux kernel community after they lost free use of the proprietary BitKeeper tool.

    In 2005, the relationship between the community that developed the Linux kernel and the commercial company that developed BitKeeper broke down, and the tool’s free-of-charge status was revoked. This prompted the Linux development community (and in particular Linus Torvalds, the creator of Linux) to develop their own tool

    Secondary source: book Pro Git, 1.2 Getting Started: A Short History of Git, git-scm.com (Apress), by Scott Chacon and Ben Straub. Read 27 November 2026.

    From the Pro Git book hosted on the Git project's site. Torvalds's own 2005 messages on lore.kernel.org were behind a bot challenge and could not be read.

    Connects: Linus Torvalds, Git

    Link to this fact

  9. 2005 Hostility and adoption

    Google starts paying students to contribute.

    Google has run Summer of Code, which pays new contributors to work on open source projects with mentors, since 2005.

    Since 2005, the Google Summer of Code program has connected 21,000+ new open source contributors from 123 countries with 20,000+ mentors from 138 countries.

    Primary source: document About Google Summer of Code, Google. Read 27 November 2026.

    The figures are Google's own, as shown on the programme page on the day it was read.

    Connects: Google

    Link to this fact

  10. November 2006 Hostility and adoption

    Sun commits to releasing Java under the GPL.

    In November 2006 Sun Microsystems committed to releasing Java under the GPL, a move the Free Software Foundation welcomed.

    The Free Software Foundation (FSF) welcomed the public commitment from Sun Microsystems to distribute its proprietary Java platform under the GNU General Public License (GPL)

    Primary source: press-release Sun begins releasing Java under the GPL, Free Software Foundation, published 15 November 2006. Read 27 November 2026.

    This is the FSF's press release of 15 November 2006, primary for the FSF's reaction and second-hand for Sun's announcement; Sun's own release (13 November 2006 by other accounts) is no longer online and could not be fetched.

    Connects: Richard Stallman, Sun Microsystems, Free Software Foundation, GNU General Public License
