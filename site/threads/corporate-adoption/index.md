# Corporate adoption

How companies went from tolerating open source to building their businesses on it, and then to buying its institutions.

### February 1995: The Apache Group formed in February 1995, when eight webmasters began co-ordinating their patches to the NCSA web server.

Step 1. Webmasters pool their patches and create the dominant web server.

> By the end of February, eight core contributors formed the foundation of the original Apache Group

- Source (primary, document): [About the Apache HTTP Server Project](https://httpd.apache.org/ABOUT_APACHE.html), The Apache Software Foundation. Read 27 November 2026.
- Connects: Brian Behlendorf, Apache Group and Apache Software Foundation
- Fact id: `apache-group-1995`

### 22 January 1998: On 22 January 1998 Netscape announced that it would publish the source code of the next generation of its Communicator browser.

Step 2. A listed company opens its main product.

> MOUNTAIN VIEW, Calif. (January 22, 1998) — Netscape Communications Corporation (NASDAQ: NSCP) today announced bold plans to make the source code for the next generation of its highly popular Netscape Communicator client software available for free licensing on the Internet.

- Source (primary, press-release): [January 22, 1998: the Beginning of Mozilla (reproduces the Netscape press release in full)](https://blog.lizardwrangler.com/?p=187), Mitchell Baker's blog (Lizard Wrangling), published 22 January 1998. Read 27 November 2026.
- Note: The press release is read as reproduced in full by Mitchell Baker (later chair of Mozilla) on her blog in 2008. The same opening paragraph was forwarded to the Linux kernel mailing list on 22 January 1998. The Netscape original survives only in the Internet Archive, which could not be reached from this machine.
- Connects: Netscape Communications, Netscape source code announcement
- Fact id: `netscape-announcement-1998`

Step 3. A Linux distributor becomes a public company.

### 2005: Git was created in 2005 by Linus Torvalds and the Linux kernel community after they lost free use of the proprietary BitKeeper tool.

Step 8. The kernel developers build their own version control tool.

> In 2005, the relationship between the community that developed the Linux kernel and the commercial company that developed BitKeeper broke down, and the tool’s free-of-charge status was revoked. This prompted the Linux development community (and in particular Linus Torvalds, the creator of Linux) to develop their own tool

- Source (secondary, book): [Pro Git, 1.2 Getting Started: A Short History of Git](https://git-scm.com/book/en/v2/Getting-Started-A-Short-History-of-Git), git-scm.com (Apress). Read 27 November 2026.
- Note: From the Pro Git book hosted on the Git project's site. Torvalds's own 2005 messages on lore.kernel.org were behind a bot challenge and could not be read.
- Connects: Linus Torvalds, Git
- Fact id: `git-created-2005`

- Fact id: `sun-java-gpl-2006`
