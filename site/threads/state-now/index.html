Where things stand

The open questions of 2018 to 2026, each from the statements of the parties.

  1. 16 October 2018 Strain and stewardship

    The vendors' complaint: cloud providers sell their software as a service.

    MongoDB said the one substantive change in the SSPL was that anyone offering MongoDB as a service must open source the software used to run that service.

    The only substantive change is an explicit condition that any organization attempting to exploit MongoDB as a service must open source the software that it uses to offer such service.

    Primary source: press-release MongoDB Issues New Server Side Public License for MongoDB Community Server, MongoDB, Inc., published 16 October 2018. Read 27 November 2026.

    Connects: MongoDB, Inc., Server Side Public License

  2. 1998 The label

    The rule their new licences break.

    Criterion 6 of the Open Source Definition forbids a licence from restricting the fields in which a program may be used, including use in a business.

    The license must not restrict anyone from making use of the program in a specific field of endeavor. For example, it may not restrict the program from being used in a business, or from being used for genetic research.

    Primary source: document The Open Source Definition, Open Source Initiative. Read 27 November 2026.

    Quoted from the current text of the definition. This is the clause the OSI cites against licences that restrict cloud providers.

    Connects: Open Source Initiative, The Open Source Definition

    Link to this fact

  3. 19 January 2021 Strain and stewardship

    The OSI's ruling.

    On 19 January 2021 the Open Source Initiative stated that the SSPL is not an open source licence, calling such licences "fauxpen" source.

    Fauxpen source licenses allow a user to view the source code but do not allow other highly important rights protected by the Open Source Definition, such as the right to make use of the program for any field of endeavor.

    Primary source: press-release The SSPL is Not an Open Source License, Open Source Initiative, published 19 January 2021. Read 27 November 2026.

    Connects: Open Source Initiative, Elastic, MongoDB, Inc., Server Side Public License, The Open Source Definition

    Link to this fact

  4. 20 September 2023 Strain and stewardship

    The community response: an open source alternative under a foundation.

    On 20 September 2023 the Linux Foundation announced OpenTofu as an open source alternative to Terraform.

    Today, the Linux Foundation announced the formation of OpenTofu, an open source alternative to Terraform's widely used infrastructure as code provisioning tool.

    Primary source: press-release Linux Foundation Launches OpenTofu: A New Open Source Alternative to Terraform, The Linux Foundation, published 20 September 2023. Read 27 November 2026.

    The OpenTofu manifesto, also read, says: "we created a fork of Terraform".

    Connects: The Linux Foundation, OpenTofu, HashiCorp, Business Source License 1.1

  6. 29 March 2024 Strain and stewardship

    The supply chain is attacked through an upstream project.

    On 29 March 2024 Andres Freund reported to the oss-security list that the xz compression library had been backdoored upstream, in a way that compromised SSH servers.

    The upstream xz repository and the xz tarballs have been backdoored.

    Primary source: mailing-list backdoor in upstream xz/liblzma leading to ssh server compromise, oss-security mailing list (Openwall), by Andres Freund, published 29 March 2024. Read 27 November 2026.

    Connects: Andres Freund, The xz backdoor

  7. 29 August 2024 Strain and stewardship

    Elastic returns to an OSI-approved licence.

    Banon wrote that using an OSI-approved licence was what allowed Elastic to use the term "open source" again.

    But being able to use the term Open Source, by using AGPL, an OSI approved license, removes any questions, or fud, people might have.

    Primary source: own-post Elasticsearch is open source, again, Elastic, by Shay Banon, published 29 August 2024. Read 27 November 2026.

  8. 10 December 2024 Strain and stewardship

    European law defines open source stewards.

    The Act creates a new legal category, the open source software steward, for bodies that sustain open source products used commercially, under a lighter regime than manufacturers.

    the novel legal category of open-source software stewards is introduced. These are legal persons who provide support on a sustained basis for the development of such products which are intended for commercial activities, and who play a main role in ensuring their viability, and are subject to a light-touch and tailor-made regulatory regime.

    Primary source: document The Cyber Resilience Act and open source, European Commission. Read 27 November 2026.

    From the European Commission's explanatory page. The text of the Regulation on EUR-Lex returned a 202 challenge page and could not be read with the fetch tool.

    Connects: European Union, Cyber Resilience Act (Regulation (EU) 2024/2847)

    Link to this fact

  9. 10 December 2024 Strain and stewardship

    Non-commercial open source stays outside the law.

    The Commission says only open source software supplied in the course of a commercial activity falls within the Act.

    only free and open-source software that is made available on the market, and therefore supplied for distribution or use in the course of a commercial activity, falls in scope of the Cyber Resilience Act.

    Primary source: document The Cyber Resilience Act and open source, European Commission. Read 27 November 2026.

    Connects: European Union, Cyber Resilience Act (Regulation (EU) 2024/2847)

    Link to this fact

  10. 28 October 2024 Strain and stewardship

    The OSI defines open source AI.

    On 28 October 2024 the Open Source Initiative released version 1.0 of its Open Source AI Definition.

    After a year-long, global, community design process, the Open Source Definition (OSAID) v.1.0 is available for public use.

    Primary source: press-release The Open Source Initiative Announces the Release of the Industry's First Open Source AI Definition, Open Source Initiative, published 28 October 2024. Read 27 November 2026.

    The release sentence says "the Open Source Definition (OSAID)"; the document released is the Open Source AI Definition.

    Connects: Open Source Initiative, The Open Source AI Definition 1.0

    Link to this fact

  11. 28 October 2024 Strain and stewardship

    It asks for information about training data.

    The Open Source AI Definition requires detailed information about the training data, enough for a skilled person to build a substantially equivalent system, but not the training data itself.

    Data Information: Sufficiently detailed information about the data used to train the system so that a skilled person can build a substantially equivalent system.

    Primary source: document The Open Source AI Definition 1.0, Open Source Initiative, published 28 October 2024. Read 27 November 2026.

    That the data itself is not required is the reading of the definition's text and is the point its critics attack; see the Software Freedom Conservancy and FSF facts.

    Connects: Open Source Initiative, The Open Source AI Definition 1.0

    Link to this fact

  12. 22 October 2024 Strain and stewardship

    The FSF wants the data itself.

    A week earlier the Free Software Foundation had said its own criteria for free machine learning applications would require the raw training data to carry the four freedoms.

    it is working on a statement of criteria for free machine learning applications, which will require the software, as well as the raw training data and associated scripts, to grant users the four freedoms.

    Primary source: press-release FSF is working on freedom in machine learning applications, Free Software Foundation, published 22 October 2024. Read 27 November 2026.

    Connects: Free Software Foundation, The Open Source AI Definition 1.0

    Link to this fact

  13. 31 October 2024 Strain and stewardship

    The Software Freedom Conservancy says the definition erodes the term.

    The Software Freedom Conservancy's Bradley Kuhn criticised the definition for not requiring public disclosure of training sets, and said the OSI should not have published it yet.

    the OSAID fails to require reproducibility by the public of the scientific process of building these systems, because the OSAID fails to place sufficient requirements on the licensing and public disclosure of training sets

    Primary source: own-post Open Source AI Definition Erodes the Meaning of "Open Source", Software Freedom Conservancy, by Bradley M. Kuhn, published 31 October 2024. Read 27 November 2026.

    Connects: Software Freedom Conservancy, Open Source Initiative, The Open Source AI Definition 1.0

    Link to this fact

    GitHub's own figures; they cover private projects as well and are not a measure of open source alone.
